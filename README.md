# Feetech_ST3215_ST3250

Настольная панель с русским интерфейсом для сервоприводов Feetech **ST3215** и **ST3250**. Программа работает с одной полудуплексной шиной STS TTL через USB-адаптер. Доступны поиск приводов, смена ID, управление положением и просмотр обратной связи. Попробовать интерфейс можно на трёх виртуальных моторах.

## Возможности

| Функция | Что делает программа |
| --- | --- |
| Поиск на шине | Проверяет выбранные ID от 0 до 253 включительно, показывает ход поиска и считывает модель, режим и пределы найденных приводов. Поиск можно остановить и запустить снова. |
| Позиционное управление | Задаёт положение, скорость и ускорение одному приводу или группе. Для группы вычисляет общий допустимый диапазон и подтверждает запись отдельно для каждого ID. |
| Удержание | Перед включением момента считывает фактическое положение и задаёт его как цель. Удержание можно снять у выбранного привода или группы. |
| Движение вперёд-назад | Перемещает один привод между двумя точками вокруг его фактической позиции. Использует заданную амплитуду, скорость и ускорение. |
| Настройка привода | Меняет ID и позволяет переключить режим скорости (1) в режим позиции (0). Изменения записываются в EEPROM и проверяются чтением. |
| Обратная связь | Показывает отправленную позицию, цель из регистра привода, фактическую позицию, напряжение, температуру, ток, скорость, нагрузку и состояние. Рисует график цели и факта за 30 секунд. |
| Диагностика | Отмечает потерю связи и устаревшие измерения, повторяет опрос, записывает ошибки и результаты операций в **Журнал**. |

## Быстрый старт

Скачайте исходники через **Code → Download ZIP** или клонируйте репозиторий следующей командой.

```bash
git clone https://github.com/garabot11/Feetech_ST3215_ST3250.git
cd Feetech_ST3215_ST3250
```

Для запуска нужны **Python 3.10 или новее**, Tkinter и графический сеанс. Команды выполняются из каталога с этим README. Наличие Tkinter можно проверить командой `python3 -m tkinter` или `py -m tkinter` в Windows. В Ubuntu и Debian модуль можно установить командой `sudo apt install python3-tk` для системного Python.

### Демо без оборудования

```bash
python3 -m feetech_panel --demo
```

В Windows используйте `py -m feetech_panel --demo`. В открытой программе демо можно запустить кнопкой **Демо**, когда порт закрыт. Для виртуальной шины достаточно Tkinter.

1. Дождитесь появления трёх строк и выберите **ID 1 · ST3215**. На демошине также есть **ID 2 · ST3250** и **ID 7 · ST3215**.
2. Нажмите **Удерживать**, задайте позицию **1200** и нажмите **Отправить позицию**. На графике будет видно, как **Факт** приближается к **Цели**.
3. Включите **Все столбцы**, чтобы увидеть измерения в таблице. Попробуйте **Вперёд-назад** с небольшой амплитудой и завершите его кнопкой **Остановить**.

### Запуск с USB-адаптером

Установите зависимость `pyserial` в виртуальное окружение. В Ubuntu и Debian для системного Python может потребоваться пакет `python3-venv`.

**Linux и macOS**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m feetech_panel
```

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m feetech_panel
```

## Подключение и первое движение

1. При выключенном питании соедините мотор с USB-адаптером для полудуплексной шины **STS TTL**. Подключите сигнальную линию, общую землю и питание по схеме адаптера. Для 12-вольтовых исполнений сверяйте маркировку приводов и допустимое напряжение адаптера. Рассчитайте источник питания с учётом тока одновременно работающих моторов. [ST3215-C018](https://ftservo.github.io/ftservo-wiki/en/products/models/st-3215-c018/main/) · [ST3250-C001](https://ftservo.github.io/ftservo-wiki/en/products/models/st-3250-c001/main/)
2. Подключите адаптер к компьютеру, подайте питание на привод и нажмите **Обновить**. Выберите порт или введите путь вручную, например `/dev/ttyUSB0` в Linux или `COM3` в Windows. Закройте другие программы, которые используют этот порт.
3. В поле **Бод** укажите скорость, настроенную на приводах. Панель предлагает **1 000 000 бод** по умолчанию. Задайте диапазон **ID от … до …** и нажмите **Подключить**. Поиск начнётся автоматически. Полный проход по диапазону 0–253 обычно занимает около 8 секунд. Поиск можно повторить кнопкой **Найти моторы**.
4. Для первой проверки выберите один привод со свободным ходом. Если показан режим скорости (1), переведите привод в режим позиции по инструкции ниже. Нажмите **Удерживать**. В поле **Позиция** задайте цель на несколько десятков отсчётов от значения **Факт** в пределах безопасного хода. Нажмите **Отправить позицию**.
5. Проверьте по графику и показаниям, что привод достиг цели. Когда механизм может безопасно оставаться без момента, нажмите **Снять удержание**. Для завершения работы нажмите **Отключить**. Закрытие порта само по себе не снимает удержание.

У приводов на одной шине должна быть одинаковая скорость обмена и разные ID. После добавления приводов повторите поиск по их адресам. Программа опрашивает найденные устройства по очереди, поэтому при увеличении их числа обновления для отдельного привода приходят реже.

## Управление положением

Панель поддерживает однооборотный режим позиции (0) с разрешением 1. Один оборот соответствует 4096 отсчётам. Если привод ограничен механически, выбирайте цели в пределах фактического свободного хода даже при более широких пределах в настройках.

| Поле | Диапазон и назначение |
| --- | --- |
| **Позиция** | 0–4095 отсчётов, с учётом пределов, считанных из привода. Задаётся ползунком или числом. **Взять факт** подставляет текущую позицию выбранного привода. |
| **Скорость** | Целое число от 1 до 32 767 в единицах регистра STS. Физический масштаб зависит от настройки привода. |
| **Ускорение** | Целое число от 1 до 254 в единицах регистра STS. |

Команда отправляется кнопкой **Отправить позицию** или клавишей **Enter** в одном из полей движения. Для отправки нужны свежая обратная связь, включённое удержание и отсутствие ошибок привода. [Таблица регистров Feetech STS](https://ftservo.github.io/ftservo-wiki/en/reference/parameter/memory-sts/)

Для группового движения выделите несколько строк через **Ctrl** или **Shift**. Кнопка **Выбрать доступные** выделяет поддерживаемые приводы со свежей обратной связью. Включите удержание и задайте одну общую позицию в пределах, показанных у ползунка. Программа отправит команды последовательно и покажет число подтверждений, например **3/3**. Если нужны разные позиции, отправьте задания по одному приводу.

### Движение вперёд-назад

1. Выберите один привод и нажмите **Удерживать**. Задайте скорость и ускорение.
2. Выберите амплитуду ползунком **Амплитуда ±… отсч.** и нажмите **Вперёд-назад**. Программа берёт фактическую позицию в момент запуска за центр и по очереди отправляет цели «центр + амплитуда» и «центр − амплитуда». Обе точки должны попадать в пределы привода.
3. Нажмите **Остановить**. Пока есть связь и включён момент, панель считывает текущую позицию и задаёт её как цель удержания. Кнопка **Снять удержание** завершает цикл и отключает момент.

Цикл также прекращается при потере обратной связи, ошибке привода или если он 5 секунд не приближается к цели. Если подтвердить остановку не удалось, панель выводит сообщение в журнал. Проверьте состояние механизма на стенде.

### Переключение в режим позиции

1. Выберите один поддерживаемый привод в **режиме скорости (1)** и нажмите **Снять удержание**.
2. Нажмите **Режим позиции** и подтвердите изменение. Настройка сохраняется после выключения питания. Программа проверяет разрешение и пределы, а затем перечитывает режим и восстанавливает блокировку EEPROM.
3. Дождитесь сообщения **Режим позиции (0) подтверждён**, затем включите удержание для отправки позиционных команд.

## Как читать обратную связь

| Показание | Что означает |
| --- | --- |
| **Подано** | Последняя позиционная команда, которую панель отправила и подтвердила повторным чтением регистров. |
| **Цель** | Заданное положение, которое сейчас записано в регистре привода. |
| **Факт** | Измеренное положение привода. |
| **Разница** | Цель минус фактическое положение в отсчётах. |

При выборе одного привода график показывает **Цель** пунктиром и **Факт** сплошной линией. Под графиком отображаются напряжение, температура, фазный ток, скорость и нагрузка как процент заполнения ШИМ. **Все столбцы** добавляет в общую таблицу скорость, напряжение, температуру и ток по каждому приводу. Столбец **Состояние** показывает связь, движение или ошибку, сообщённую приводом. Ошибки и результаты команд можно открыть кнопкой **Журнал**.

## Смена ID

1. Оставьте на шине один мотор. При совпадающих ID ответы шины не позволяют надёжно определить, сколько приводов подключено.
2. Найдите привод, выделите его и нажмите **Снять удержание**. Нажмите **Сменить ID** и введите новый адрес от 0 до 253. Программа проверит адрес на шине и отклонит адрес, который уже есть в списке устройств текущей сессии.
3. Дождитесь сообщения о подтверждении нового ID и проверьте строку в таблице. При первой настройке на стенде выключите и снова включите питание, затем повторите поиск для проверки сохранения адреса.
4. Настройте остальные приводы по одному и после этого подключите их вместе. [Порядок смены ID Feetech](https://ftservo.github.io/ftservo-wiki/en/reference/parameter/memory-sts/#44-changing-the-id)

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Порта нет в списке | Подключите адаптер, нажмите **Обновить** и проверьте, появился ли последовательный порт в системе. Имя порта можно ввести вручную. |
| Нет доступа к порту | Закройте другие программы, использующие порт. В Ubuntu проверьте права на устройство и членство в группе `dialout`. |
| Приводы не найдены | Проверьте питание, общую землю, сигнальную линию, совпадение скорости обмена и выбранный диапазон ID. Попробуйте подключить один привод. |
| Показания устарели или ответы повреждены | Откройте **Журнал**, проверьте соединение и убедитесь, что на шине нет повторяющихся ID. |
| Позиция не отправляется | Проверьте, включено ли удержание, есть ли свежая обратная связь и входит ли цель в пределы всех выбранных приводов. |
| Отображается только код модели | Панель может обнаружить другой привод по протоколу STS. Команды записи доступны для кодов 777 (ST3215) и 2825 (ST3250). |

## Исходники и тесты

- [`feetech_panel/ui.py`](feetech_panel/ui.py) — окно, таблица, органы управления и график.
- [`feetech_panel/worker.py`](feetech_panel/worker.py) — очередь команд, поиск и опрос в фоновом потоке.
- [`feetech_panel/bus.py`](feetech_panel/bus.py) — пакеты STS, чтение регистров и проверка записей.
- [`feetech_panel/demo.py`](feetech_panel/demo.py) — виртуальная шина для демо и тестов.
- [`tests/`](tests/) — проверки протокола и работы фонового потока.

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют поиск, смену и конфликт ID, блокировку EEPROM, пределы позиции, удержание, переключение режима, двунаправленное движение и опрос 48 виртуальных приводов. При наличии `pyserial` и поддержки PTY также запускается сквозная проверка через виртуальный последовательный порт. Для проверки работы с реальным приводом используйте раздел о первом движении.
